SECURITY & ACCESS

Financial access should be deliberate and documented.

This prototype describes good operating principles without claiming certifications the business has not verified.

01

Least-privilege access

Use the minimum account permissions needed for bookkeeping work.

02

Separate user accounts

Avoid shared credentials where supported by the platform.

03

MFA where available

Enable multi-factor authentication on financial and document systems where supported.

04

Access review

Review and remove outdated access when roles or engagements change.

05

Document handling

Define where financial documents should be uploaded and stored.

06

Incident route

Maintain a clear path for reporting suspected access or data issues.
